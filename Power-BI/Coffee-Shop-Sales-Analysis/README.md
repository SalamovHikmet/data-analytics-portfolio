# Coffee Shop Sales Analysis

## Project Overview
This project analyzes coffee shop sales data using Power BI to understand revenue performance, store performance, product category performance, transaction patterns, and sales trends over time.

## Tools Used
- Power BI
- Power Query
- Data Cleaning & Transformation
- Data Visualization

## Key Analysis
- Revenue performance by store location
- Monthly revenue trends
- Revenue by hour
- Revenue by product category
- Top products by revenue
- Revenue vs. units sold by category
- Average order value analysis
- Total transactions and units sold

## Key Insights
- Total revenue reached approximately $698.8K from 149K transactions.
- Approximately 214K units were sold, with an average order value of $4.69.
- Hell's Kitchen generated the highest revenue among the three store locations.
- Revenue showed an overall upward trend toward June.
- Coffee was the largest product category by revenue.
- Sales activity was strongest during the morning hours, particularly around 8:00–10:00.
